# לוגואים של החברות המנהלות

הלוגו לצד שם החברה נטען מ-**LogoKit** לפי הדומיין של החברה:

```
https://img.logokit.com/<domain>
```

אין קבצי לוגו בריפו. המיפוי יושב ב-`BRAND_LOGOS` שב-`scripts.js`:

| חברה | דומיין |
|---|---|
| הראל | `harel-group.co.il` |
| מנורה מבטחים | `menoramivt.co.il` |
| הפניקס | `fnx.co.il` |
| מגדל | `migdal.co.il` |
| כלל | `clalbit.co.il` |
| מיטב | `meitav.co.il` |
| אלטשולר שחם | `as-invest.co.il` |
| מור | `moreinvest.co.il` |

## נפילה למונוגרמה

כל חברה מקבלת מונוגרמה (שתי האותיות הראשונות של שמה) שמצוירת תמיד מתחת
לתמונה. חברה שאינה במיפוי, וכן כל כשל טעינה של התמונה, מציגים את המונוגרמה —
`onerror` מסיר את התמונה והמונוגרמה נחשפת. אין מצב של ריבוע ריק.

להוספת חברה: מוסיפים שורה ל-`BRAND_LOGOS` עם הדומיין שלה. שם החברה במפתח
חייב להיות זהה לשם שמוצג באשף (השם שנגזר מ-`managing_corp`).

## מה שכדאי לדעת

* הטעינה היא בקשה מהדפדפן של הגולש אל שרת חיצוני (img.logokit.com).
* אם השירות דורש מפתח, מגביל שימוש, או שאין לו לוגו לדומיין מסוים — התמונה
  נכשלת, המונוגרמה מוצגת, והדפדפן רושם שגיאת רשת אחת לכל תמונה שנכשלה.
* הלוגואים הם סימני מסחר של החברות ומשמשים לזיהוי בלבד, בלי לרמז על חסות.
