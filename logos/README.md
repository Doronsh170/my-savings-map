# לוגואים של החברות המנהלות

האשף מציג לוגו לצד שם החברה כשקיים כאן קובץ מתאים, ואם אין — מונוגרמה
(שתי האותיות הראשונות של השם). האתר עובד במלואו גם בלי אף קובץ בתיקייה הזו.

## שמות הקבצים

`BRAND_LOGOS` ב-`scripts.js` הוא המניפסט. מוסיפים אליו שורה **רק אחרי** שהקובץ
הועלה לכאן, אחרת הדפדפן ידווח על 404. המיפוי הפעיל:

| חברה | קובץ |
|---|---|
| מנורה מבטחים | `menora.png` |
| מיטב | `meitav.png` |
| מור | `mor.png` |
| מגדל | `migdal.png` |
| כלל | `clal.png` |
| הראל | `harel.png` |
| אלטשולר שחם | `altshuler.png` |
| הפניקס | `phoenix.png` |
| אנליסט | `analyst.png` |
| ילין לפידות | `yelin.png` |
| איילון | `ayalon.png` |

לדוגמה, אחרי העלאת `harel.svg` מוסיפים ל-`BRAND_LOGOS`:

```js
const BRAND_LOGOS = {
  'הראל': 'harel.svg'
};
```

הערך הוא שם הקובץ המלא כולל סיומת, כך ש-PNG עובד באותה צורה: `'הראל': 'harel.png'`.

שם החברה במפתח חייב להיות זהה לשם שמוצג באשף (השם שנגזר מ-`managing_corp`).

## דרישות הקובץ

* פורמט SVG או PNG, רקע שקוף.
* ריבועי ככל האפשר; הקובץ מוצג בתוך ריבוע 40×40 עם `object-fit: contain`.
* לוגו כהה על רקע שקוף עובד היטב — הרקע מאחורי הלוגו לבן.
* הקבצים מועתקים ל-`_site/logos` בזמן ה-build (`netlify.toml`).

## סימני מסחר

הלוגואים הם סימני מסחר של החברות ומשמשים כאן לזיהוי בלבד. אין להציג אותם
בצורה שמרמזת על חסות או שיוך. השג את הקבצים ממקור רשמי (ערכת מותג / אתר החברה)
לפני העלאה.
